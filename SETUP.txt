HELLO EDUCATION — CLOUDFLARE PAGES SETUP

This ZIP is ready for Cloudflare Pages Direct Upload. index.html is at the root.
No build step, Node installation, database, API key, or ChatGPT account is needed
by visitors. The package contains the editable HTML, CSS, JavaScript and images.
Google Fonts loads the Outfit and DM Sans typefaces online.

DEPLOY
1. Open Cloudflare dashboard > Workers & Pages.
2. Choose Create application > Get started > Drag and drop your files
   (choose Pages if the dashboard asks which product).
3. Name the project, upload this ZIP, and select Deploy site / Save and Deploy.
4. Open the resulting pages.dev address to review the page.

CONNECT YOUR DOMAIN
1. Open the Pages project > Custom domains > Set up a domain.
2. Enter your domain or subdomain and follow the prompts.
3. For a root domain, it must be a Cloudflare zone with Cloudflare nameservers.
   Cloudflare can create the required DNS record after confirmation.
4. Add www separately if you want both addresses to work. Choose one primary
   address and redirect the other to it.
5. Wait for the custom domain and HTTPS certificate to become active.
Always register the domain in the Pages project's Custom domains section,
not only by creating a DNS record.

CUSTOM DOMAIN SEO
The exported page does not point its canonical URL at the ChatGPT-hosted copy.
After choosing your primary domain, add these tags inside <head> in index.html,
replacing example.com with your actual primary domain:
<link rel="canonical" href="https://example.com/">
<meta property="og:url" content="https://example.com/">
